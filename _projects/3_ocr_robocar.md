## Overview
OCR-Guided Treasure Hunter is the UCSD Team 16 metapackage, a comprehensive ROS2-based autonomous vehicle framework designed for autonomous navigation, lane following, and intersection handling. The system integrates multiple sensors, actuators, path planning algorithms, and control systems to enable fully autonomous operation.

## Highlights
- ROS2 metapackage for a robocar platform
- OCR-guided intersection handling and navigation
- Modular pipeline with sensing, planning, and control

## Tech
- ROS2, Python, Docker
